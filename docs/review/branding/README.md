# Branding review captures

- `branding-board.png`: browser screenshot of `preview.html`, using generated
  asset files. iPhone, PWA and Android-themed shapes are simulated masks, not
  screenshots taken on native devices.
- `splash-mobile.png`: actual release web splash at 390 x 844. Flutter bootstrap
  was temporarily blocked in the screenshot browser to hold the launch screen.
- `app-pink.png` and `app-cyan.png`: actual release app at 1440 x 1040 with
  synthetic local profiles Mia and Leo. No family photos or stored user data.
  The logo frame and glow follow the active profile color.

Native Android/iOS assets were regenerated and visually checked through the
review board. Native installs were not tested on a phone in this change.
